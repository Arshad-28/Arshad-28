## FEATURED WORK

### 🛡️ Multi-Cloud Threat & Anomaly Detection

A platform-focused project centered on **Nexus Guard** — a system built around the idea of detecting threats and anomalies across multi-cloud environments in a unified, coherent way.

**Purpose:** Modern infrastructure rarely lives in one place — teams operate across multiple cloud providers simultaneously, and that fragmentation makes threats harder to see. This project's direction is about pulling that visibility into one place: surfacing anomalies and security signals from across cloud environments through a single, clear interface.

**Why it matters:** Security tooling is only as useful as it is understandable. The focus here isn't just detection — it's making detection *legible*, so the people relying on it can actually act on what they see.
